# Release 0.1 — Functional Recovery

Baseline commit `f9777bf6a0aa22f0b98f1b017209aeb5bd5c358c`. The portable application is `index.html`; the runtime requires no installed dependencies. See [README.md](README.md) for launch and test commands.

## Defect register

Baseline reproduction used Playwright Chromium over local HTTP and with the original HTML opened directly. To repeat it, serve the baseline from a separate directory (`git show f9777bf:index.html > /tmp/lifespan-baseline/index.html` after creating the directory) and follow the steps below. The baseline opened directly with 81 chart points. One system Chromium build blocked `file:` navigation by administrator policy; the Playwright Chromium build could open the same file. HTTP testing on system Chromium also logged a favicon 404.

## Source verification

- **World Bank WDI**, API metadata revision 2026-11-11, retrieved 2026-11-26. Bundled 3,705 records for 16 countries and three aggregates, in years, for all three sex selections over 1960–2024. Indicators are period life expectancy at birth under the mortality conditions of the reference period. WDI publishes source estimates as well as reported values. Regression samples include Hungary 2024 total 76.7243902439025, Austria 2024 female 84.3, Germany 2024 male 78.5 and Japan 1990 male 75.92. The API query uses `format=json&date=1960:2024&per_page=5000` with the 19 country/aggregate codes from the snapshot. [Total](https://data.worldbank.org/indicator/SP.DYN.LE00.IN) · [Male](https://data.worldbank.org/indicator/SP.DYN.LE00.MA.IN) · [Female](https://data.worldbank.org/indicator/SP.DYN.LE00.FE.IN)
- **KSH STADAT 4.1.1.44**, Hungarian HLY at birth and at 65, by sex, 2006–2025. Spot-checked 2006, 2024 and 2025 against the published table. The page documents the switch to the Sullivan method in 2015 and a change in the survey question in 2019. [KSH](https://www.ksh.hu/stadat_files/ege/hu/ege0041.html)
- **OECD / European Commission**, Eurostat HLY reference year 2024. Compared the embedded country entries to source workbooks for Figure 3.3 and 3.4, version 1 updated 2026-11-25. Years with and without limitations at 65 are age-conditional components; for Austria's women 9.3 + 12.4 = 21.7 years, with about 43% without activity limitation. A Hungarian HLY value in the historical chart can differ from the OECD workbook because the chart uses KSH's series for Hungary. HLY uses self-reported activity limitation and is distinct from WHO HALE. [Figure 3.3](https://stat.link/o2witf) · [Figure 3.4](https://stat.link/sfocke)
- **OECD Pensions at a Glance 2025**, Table 3.5 and accompanying text, model reference year 2024. Normal retirement age assumes a full career from age 22. Samples match the model for Hungary (65.0 male, 62.0 female), Austria (65.0 male, 60.5 female), Germany (66.2) and Japan (65.0), and the OECD averages are 64.7 male and 63.9 female. [OECD](https://www.oecd.org/en/publications/pensions-at-a-glance-2025_e40274c1-en/full-report/current-retirement-ages_0f63b747.html)
- **OWID-hosted sources**, current CSV headers checked against actual downloads for UN WPP historical estimates, UN WPP projections and WHO HALE. Projection and historical columns have explicit names and disjoint period filters. The suite uses deterministic responses for browser success tests. [History](https://ourworldindata.org/grapher/life-expectancy-unwpp) · [Projection](https://ourworldindata.org/grapher/future-life-expectancy-projections) · [HALE](https://ourworldindata.org/grapher/healthy-life-expectancy-at-birth)

## Test evidence and limitations

- Executed on 26 November 2026 with Playwright 1.65.1 and Chromium 159, using desktop and Pixel 7 emulation. The final command was `PLAYWRIGHT_BROWSERS_PATH=/tmp/lifespan-browsers npm test -- --workers=2`. It completed with 19 passed, one skipped and zero failures in 28.1 seconds. The suite checks SVG point values, series counts and gaps, filter and navigation state, CSV output, conditional retirement arithmetic and browser errors. The desktop pointer test is deliberately skipped in the mobile project.
- Live browser requests to World Bank and OWID failed with `net::ERR_CERT_AUTHORITY_INVALID` in this environment. All four buttons displayed a Hungarian failure message and left the bundle usable. Direct source downloads via command-line HTTPS were successful for the source validation above. Successful online imports in the browser were exercised with fixtures; live browser success remains unverified.
- Offline life expectancy ends in 2024 and begins in 1960. The 1950s require an optional UN WPP load or a sourced CSV. HLY has limited coverage. Historical pension ages, effective exit and total HLY have no bundled series. No unsupported data is filled in. CSV exports preserve raw values even while the chart is in change mode. Imports and optional downloads are session-only.
- Age-65 estimates are period measures conditional on reaching 65. Cohort, individual survival and age-specific retirement projections lack the underlying tables. The existing scenario and research guide remain educational, and the prototype has no map. Safari, Firefox and physical mobile devices were outside this test matrix.
